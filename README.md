# КИПиА Калькулятор

Офлайн-приложение для быстрых расчётов на работе и во время обучения КИПиА.

## Первая версия

- конвертер давления: Па, кПа, МПа, бар, кгс/см², мм рт. ст., мм вод. ст.;
- пересчёт сигнала 4–20 мА в физическую величину и обратно;
- конвертер длины;
- перевод температуры;
- закон Ома;
- справочник приставок СИ.

Приложение не требует интернета. Минимальная версия Android — 6.0, целевое устройство — Xiaomi Mi 9 NFC с Android 10.

## Получение APK

Откройте вкладку **Actions**, выберите последнюю успешную сборку **Build Android APK** и скачайте архив **KIPiA-Calculator-APK**. Внутри находится установочный `app-debug.apk`.

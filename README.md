# Помощник КИПиА

Полноценное офлайн-приложение для начинающего работника КИПиА: инженерные расчёты, понятный справочник, связанные технические термины и локальные цветные схемы.

## Возможности

- конвертеры давления, температуры и длины в формате «из → в»;
- пересчёт токовой петли 4–20 мА в физическую величину и обратно;
- электрический калькулятор U, I, R, P с инженерными единицами;
- расчёт цены деления шкалы;
- приставки СИ от кветто 10⁻³⁰ до кветта 10³⁰;
- офлайн-справочник по приборам, электрике, давлению, температуре, расходу, уровню, газовому анализу и метрологии;
- поиск по названиям и содержанию статей;
- нажимаемые технические термины со связанными статьями;
- локальные векторные схемы с полноэкранным масштабированием;
- светлая и тёмная темы.

Интернет, регистрация и аккаунт для работы приложения не требуются.

## Архитектура

- `Engineering.kt` — централизованные единицы, коэффициенты, формулы, разбор и форматирование чисел;
- `ReferenceData.kt` — единое локальное хранилище категорий, статей и связанных терминов;
- `TechnicalDiagramView.kt` — масштабируемые цветные технические схемы, отрисовываемые локально;
- `MainActivity.kt` — навигация, экраны, темы, поиск и представление данных;
- `EngineeringTest.kt` — тесты контрольных расчётов.

Справочник построен на моделях данных: новая категория, статья или термин добавляются в `ReferenceData`, а поиск и экраны формируются автоматически.

## Совместимость

- минимальная версия: Android 6.0 (API 23);
- целевая версия: Android 15 (API 35);
- Xiaomi Mi 9 NFC с Android 10 поддерживается.

## Сборка

### GitHub Actions

Каждый push в `main` запускает `.github/workflows/build-apk.yml`. Успешная сборка создаёт артефакт `Pomoshchnik-KIPiA-APK` с установочным файлом `Pomoshchnik-KIPiA.apk`.

### Android Studio

1. Открыть корень проекта.
2. Дождаться Gradle Sync.
3. Выбрать `Build → Build App Bundle(s) / APK(s) → Build APK(s)`.
4. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Контрольные примеры

- `0,6 МПа → 6,1183 кгс/см²`;
- `1500 мм → 1,5 м`;
- диапазон `0–1,6 МПа`: `12 мА → 0,8 МПа → 50 %`;
- шкала `0–1,6 МПа`, 80 промежутков: `0,02 МПа/деление`;
- `I = 0,25 А`, `R = 200 Ом`: `U = 50 В`, `P = 12,5 Вт`.

Расчёты являются рабочей подсказкой и не заменяют паспорт прибора, технологический регламент и правила безопасности.
